# 회의체 운영 AI Agent
    AI를 활용하여, (1) 누수없이 적시에 과제를 관리하고, (2) 사업 조직의 보고서 수준을 제고하며, (3) 회의체 운영자가 가진 암묵지의 AI Asset화 및 운영 효율화 목적의 Multi-agent 서비스 
   
    - 회의체를 운영함에 있어 각각의 작은 파트에서 기능하는 에이전트가 아닌, 하나의 회의체가 연중 연속적으로 운영되어 조직내 전략적인 의사결정을 돕는 Multi-agent 서비스에요.
    실제로 구현이 된다면, 기획 담당 조직에서 수기로 이루어지고 있는 많은 low-level의 업무를 AI agent가 대신할 수 있어요.
    - Agent 워크플로우 w/ human-in-the-loop
        
        
        |   1. To-do 과제 도출  | 1-1. | 전략기획 담당자👤 | 주요 보고자료를 과제 추출 에이전트에 업로드  |
        | --- | --- | --- | --- |
        |  | 1-2. | [AI] 과제 추출 Agent 🤖 | 보고자료 기반 To-do 과제 추출 → Due date, 담당 조직, 주관 회의체 맵핑 |
        |  | 1-3. | 전략기획 담당자👤 | AI의 산출결과 검증 후 To-do 과제 장부 업데이트 및 담당 조직에 따라 회의 아젠다 assign |
        | 2. 회의 준비 | 2-1. | 발제 조직👥 | 발제 자료 작성 → 전략기획 검토 → Teams 업로드 |
        |  | 2-1. | [AI] 보고서 검토 Agent 🤖 | 사업 보고서 작성 보조  |
        | 3. 발제 자료 Check  | 3-1.  | 전략기획 담당자👤 | 1에서 도출된 회의 아젠다 반영 여부 점검 및 대시보드 업데이트 |
        | 4. 회의 진행  | 4-1.  | [AI] 회의록 작성 Agent 🤖 | 회의록 작성 및 요약 |
        | 5. 피드백 기반 To-do 과제 도출 | 5-1. | 전략기획 담당자👤 | 회의록 게시 및 과제 추출 에이전트에 업로드  |
        |  | 5-2.  | [AI] 과제 추출 Agent 🤖 | 보고/회의자료 기반 To-do 과제 추출 → Due date, 담당 조직, 주관 회의체 맵핑 (1. To-do 과제 도출로 돌아가서 프로세스 repeat)  |
        | 6. 보고서 및 의사결정사항 공유 | 6-1.  | [AI] 자료 생성 Agent 🤖 | 보고 결과물에 대해 카드뉴스 형태로 C레벨, 구성원 대상 공유 자료 재가공  |
        |  | 6-2.  | 전략기획 담당자👤 | 유관 조직에 공유 자료 배포  |
    - 주관 부서 : 경영전략팀 → 서비스를 실제 사용하고자 하는 의지가 매우 강해요.
